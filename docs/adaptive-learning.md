# 自适应内核：从二元对错到错误模式诊断

> 2026-08-18 反思。用户指出的「真内核」：像硅谷自适应学习公司那样，从孩子的回答里
> 判断「哪些音读错（i/ee、th/s）、哪些拼写易错（ie/ei、b/d）、哪些语法点薄弱」，
> 针对性补课，出题不断进化——**这才是 laze.json 的真内核，数据驱动，躺着的最高境界**。

## 一、现状的缺口（诚实）

现有内核只到「二元对错」这一层：

- `know` / `wrong` 事件只记录「对还是错」，不记录**错在哪**；
- `tutorDiagnosis` 只回答「哪些词回炉/到期」，回答不了「哪个**能力单元**弱」；
- 出题是「按词表随机」，不是「按薄弱单元针对」；
- FSRS 调度的单位是「词」，但真正的学习单位是「能力单元」（一个音素、一条拼写规则、一个语法点）。

**后果**：孩子 th/s 永远分不清时，系统只会反复推「含 th 的词」，却不知道她在
「th vs s」这个音素对上薄弱——补课停留在词层面，进不到能力层面。

## 二、新内核：三层

```
L1 错误模式（一答一记）
  拼写题答错 → classifySpellingError(输入, 答案) → 混淆对（ie/ei、b/d、双写…）
  听音/读错 → 词的 IPA 音素 → 音素混淆（ɪ/iː、θ/s、l/r…）
  语法题 → 关联 GRAMMAR_POINTS（过去式 ↔ 不规则动词）

L2 薄弱单元诊断（聚合）
  diagnoseWeaknesses(轨迹) → [{ unit:"spelling:ie-ei", count:3, words:[…] }, …]
  归因到「可补课的单元」，而不是停在单个词

L3 针对性出题 + 进化（控制器）
  generateTargeted(薄弱单元, seed) → 从词库选「含该模式」的词，确定性出题
  答对 → 单元强度上升；答错 → 继续强化；单元收敛 → 换下一个薄弱单元
  laze.json storyboard v0.2 条件边 = 这个进化的显式表达
```

## 三、关键设计决定

1. **错误模式写进轨迹**（不是旁路存储）：`wrong` 事件增加 `input`（孩子的错误拼写）
   ——轨迹即日志的原则不破，错误模式可重放、可审计。
2. **混淆对表数据驱动**（先小后大）：10 音素对 + 10 拼写对起步，
   每对带 id/中文说明/示例——表本身像词库一样可扩展、可署名。
3. **确定性**：诊断聚合与针对性出题都是纯函数（同轨迹同 seed 恒同结果），
   与 FSRS 同一条「可重放」纪律。
4. **不强推**：这是对现有 know/wrong 的**增强**，不是推倒——旧的二元对错照常工作，
   有 `input` 的事件多带一层信息，无 `input` 的旧事件照常折叠。

## 四、与「躺着的最高境界」的关系

躺着的最高境界 = 孩子只管躺着，系统自动完成
「诊断（哪个单元弱）→ 出题（针对那个单元）→ 进化（题随诊断变）→ 报告（家长看得懂）」
的完整闭环。孩子不安排学习，系统替她安排——这才是「学习即仿真」的控制器形态。

## 五、典型学习者画像（设计驱动，匿名）

一位真实学习者的具体薄弱点（去名化）：

| 学科 | 薄弱点 | 现状覆盖 | 缺口 |
|---|---|---|---|
| 数学 | 百分比、多項式、計算、坐標旋轉 | ❌ 计算部分覆盖（进位/借位/口诀） | 百分比/多项式/坐标旋转**需要新题型生成器**（非算术） |
| 英语 | 音節讀錯（重音）、輔音讀錯 | ⚠️ 辅音部分覆盖（th/s、l/r、v/w、n/ng） | 音节重音**需要重音标注数据 + 听音标重音题型**（不同于最小对） |

**结论**：现有三维修道是「算术/拼写/最小对音素」——该学习者的薄弱点一半在覆盖内（计算、
部分辅音），一半需要**新题型生成器**（百分比/多项式/坐标）与**重音标注数据**。
这验证了分类表「数据驱动、可扩展」的设计：扩展不是改引擎，是加表、加生成器。

## 六、落地顺序（每步可测、可交付）

1. **L1+L2 核心纯函数**（本轮）：混淆对表 + classifySpellingError + diagnoseWeaknesses + 测试；
2. **L1 接入**：拼写题答错时记录 `input` 到 wrong 事件；
3. **L3 出题**：generateTargeted + 考试/私教接「针对性模式」；
4. **报告**：家长视角「能力单元热力图」（哪个音/规则/语法弱）；
5. **laze.json v0.2**：storyboard 条件边显式表达「诊断→补课→进化」。
